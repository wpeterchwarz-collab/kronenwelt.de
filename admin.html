GitHub Verbindung
✓ Das GitHub-Token liegt sicher im Apps Script. In diesem Browser ist dafür nichts gespeichert.
Besser: das Token im Apps Script als Skripteigenschaft GITHUB_TOKEN eintragen. Dann ist hier nichts mehr nötig und es wird aus dem Browser gelöscht.
Cloudinary Verbindung
✓ Der Cloudinary-Zugang liegt sicher im Apps Script. Fotos werden dort nur unterschrieben und gehen direkt zu Cloudinary.
Besser: CLOUDINARY_KEY und CLOUDINARY_SECRET im Apps Script eintragen. Dann wird der Zugang aus dem Browser gelöscht.
